# Livin Foundation

> Loaded every session. To amend, follow the Amendment Process below.

## Mission
Livin convierte la gestión de las tareas del hogar en un videojuego 2D de vista
cenital estilo GBA, donde la casa real de cada familia es un mapa recorrible, para
que las personas que comparten un hogar vean de un vistazo cómo está la casa y
quién se encarga de qué.

## Principles
1. Ningún espacio se crea, elimina ni modifica como efecto secundario de otra
   acción: solo cambia lo que el usuario modifica explícitamente.
2. El juego es el medio, no el decorado: toda funcionalidad se vive dentro del
   mapa y se siente como jugar, nunca como revisar una lista o un chat.
3. El estado del hogar se lee de un vistazo en el propio mapa, sin tener que
   abrir listas ni pantallas aparte.

## Operational Context
Steering files in `.claude/memory/steering/` carry project-specific operational context
(tech stack, test strategy, conventions, team practices). Each file's `loaded-by`
frontmatter lists which skills silently incorporate it during that skill's session.
Edit steering files freely — they are not subject to the amendment process.

## Amendment Process
Documentar la justificación → aprobación explícita del equipo → verificación de
compatibilidad hacia atrás.
